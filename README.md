# Wall Be Back

Wall Be Back is a private family space designed to help relatives stay connected. It brings conversations, shared memories, events, and family profiles together in a warm, responsive interface.

## Features

- Private authentication with admin, adult, and child roles
- Family wall with posts, replies, moderation, and photo attachments
- Secure photo gallery with optimized private media
- Shared calendar and member profiles
- Real-time updates across connected devices
- Light and dark modes with multiple color palettes

## Tech Stack

- Next.js 16 and React 19
- TypeScript
- PostgreSQL with Drizzle ORM
- Tailwind CSS 4
- TanStack Query
- Zod, bcrypt.js, and Sharp
